Project integration:
- src/server.ts builds fresh McpServer instances with registered OBS tools.
- serveStdio(createServer) supports the released 2026-07-28 protocol and
  legacy clients. Keep the factory; do not reuse a single server instance.
- src/http.ts passes the factory to createMcpHandler. Stateless HTTP
  requests receive their own server/transport while sharing the OBS client.
- src/http.ts validates loopback Host/Origin headers and optionally checks
  an opaque shared bearer token. It does not implement OAuth token issuance.
- src/tools/request-tool.ts normalizes tool results and approval annotations.
- scripts/list-tools.mjs retrieves tool inventory through the public MCP
  interface; packaging must not depend on private SDK internals.

SDK 2.1 and later bound HTTP request bodies and legacy batch size by default.
The HTTP regression suite verifies those limits and subsequent availability.
SDK 2.3 tightens server/transport ownership; this project's factory pattern
already satisfies it. New optional argument-element and OAuth-audience
settings require an explicit integration decision before use.
