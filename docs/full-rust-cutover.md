# Full Rust cutover

The current executable enters the retained Rust service directly. Stdio and loopback HTTP use the same service owner; no JavaScript compatibility launcher is compiled into the native product. TypeScript remains a development oracle. [Native distribution](native-distribution.md) gives prerequisites and commands; [architecture](native-architecture.md) describes ownership and failure behavior.

## Current capability boundary

Production exposes up to 164 ordinary tools with approved host/media adapters. Advanced exposes 163 ordinary tools and excludes guarded Take, media, Stage and recovery owners. The 178-name union spans both immutable profiles. Three dynamic group controllers are conditional additions for stdio; HTTP uses static groups. Read-only mode, filters and adapter availability still apply.

The composed service owns planning/audit, Apply Scene and Capture Window, snapshots/manual Restore, guarded preparation/recovery, bounded recording and media jobs, confirmation/resume, resources and cooperating control. Advanced raw, batch, vendor, hotkey and manual output commands retain their separate policy and durable guarded-reentry barriers. See [native profiles](native-profiles.md); a visible tool or successful ACK never grants another workflow's recording, Stop or file authority.

One lazy connection attempt lets discovery and local refusals proceed while OBS is unavailable. It retains its original deadline and cleanup owners across client cancellation. A failed or uncertain operation is not automatically replayed. Owned DNS and conditional platform TLS cleanup are independent of Service success.

## Remaining release gates

Linux qualification is in progress; no Linux platform/runtime acceptance is
recorded here. Each remaining gate needs the final candidate's own source and
artifact identity:

1. Qualify the Linux build, system prerequisites, extracted runtime, helper and
   shutdown behavior, then the applicable X11 or user-authorized Wayland journey.
2. Complete production TLS review and feature-on optimized/extracted checks on
   each supported platform: authenticated secure OBS WebSocket reads, trust and
   peer-identity negatives, cancellation during resolution/connect/TLS/Upgrade,
   and joined shutdown/restart. Default builds still refuse `wss:` without
   downgrade or SDK handoff; component handshakes do not restore Source parity.
3. Rebind changed source, notices and packages, review final-head CI, and complete
   delivery and client activation. A documentation or archive update does not
   inherit a prior package hash automatically.

The optimized, package and bounded Mac gates above have recorded receipts. Linux,
production TLS, final CI and activation remain pending. No rewrite or qualification
result changes the project's GPL-2.0-only license or attribution. The acceptance
criteria concern behavior and resource custody; these results provide no capture
or encoding speed comparison.
